# Results

Generated by the scripts (not pre-filled with real study outputs):

- `table1/inputs/` — fair-comparison packs from `build_table1_inputs.py`
- `table1/generations/` — baseline PNGs from `generate_table1_baselines.py`
- `table1/per_case_system_results.*` — Table 1 scores
- `table1/aggregate_summary.json`
- `table2/per_case_results.*` — Table 2 scores
- `table2/aggregate_summary.json`
- `RiskScribe_Final_Score_Tables.docx` — written/updated by scorers when present

This package intentionally **does not** ship real evaluation scores or raw study data.
